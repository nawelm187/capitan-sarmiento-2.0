VERSION COMPLETA 1.4.0  (más lugares, íconos de Google, recorridos y guías)

1. Copiá TODO el contenido de esta carpeta adentro de tu proyecto, reemplazando archivos.
   NO borres tu carpeta data/ (tiene tu mapa real).
2. En la terminal, dentro de tu proyecto:
     node tools/apply-update.mjs
     npm run lugares
   (npm run lugares baja todos los lugares de OpenStreetMap, resalta los edificios especiales
    y arma los recorridos a pie y en auto. Tarda un minuto.)
3. npm run serve  ->  http://localhost:8080   (Ctrl+F5 para refrescar)
4. Subilo a GitHub (git add . / git commit -m "1.4.0" / git push)

Extras:
  Agregar un lugar que falte:   npm run lugares -- --agregar --nombre="Ferretería X" --tipo=ferreteria --lat=-34.17 --lng=-59.78
  Agregar un guía de turismo:   npm run guias -- --nombre="María Gómez" --contacto="+5491123456789" --idiomas=es,en
  Rehacer solo los recorridos:  npm run recorridos
